# 中文术语与来源

本期没有解包或绕过游戏资源包的加密。上游 GameData.cs 也明确其目录根据存档中的 ID 建立，并非游戏官方数据表。因此，本 Fork 的游戏术语均按上游英语标签及内部 ID 暂译，**尚未证实为官方中文**。待用户游戏内核对后可只更新字典，无须改存档字段。

科技行保留 ID 悬停提示，建筑卡保留内部类型，装备显示 ID；物资行显示 ID，建造下拉选项及新增部件标签有 ID 提示。未识别的 ID 原样保留或按英文排版显示。原始数据中的字段名、Godot 类型名、文件路径及用户自定义存档名称不翻译。
